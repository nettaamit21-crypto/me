# מחברת העסק

כאן חושבים על העסק, מחליטים, ומורידים לביצוע. כל החלטה נרשמת כאן, וכל שאלה פתוחה נשארת כאן עד שנסגרת.

## איך עובדים עם המחברת

- **כל יום ראשון בבוקר:** פותחים את `05-plan.md`, מסמנים מה נעשה ומעדכנים מספרים.
- **עלה רעיון חדש?** לפני שמתחילים אותו, בודקים מול סדנת הדגל: הוא משרת אותה, או שהוא עובר ל"חניה" (בסוף `03-flagship.md`).
- **משהו השתנה** (מחיר, מוצר, הכנסה)? מעדכנים את הקובץ הרלוונטי, לא רק בראש.
