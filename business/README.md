# מחברת העסק

כאן חושבים על העסק, מחליטים, ומורידים לביצוע. כל החלטה נרשמת כאן, וכל שאלה פתוחה נשארת כאן עד שנסגרת.

## איך עובדים עם המחברת

- **כל יום ראשון בבוקר:** פותחים את `05-plan.md`, מסמנים מה נעשה ומעדכנים מספרים.
- **עלה רעיון חדש?** לפני שמתחילים אותו, בודקים מול סדנת הדגל: הוא משרת אותה, או שהוא עובר ל"חניה" (בסוף `03-flagship.md`).
- **משהו השתנה** (מחיר, מוצר, הכנסה)? מעדכנים את הקובץ הרלוונטי, לא רק בראש.

## הקבצים

1. [`03-flagship.md`](03-flagship.md): **המסמך המרכזי.** הסדנאות, הקהל והשעות, לוח העונות לפי החגים, והשפה של כל עונה
2. [`05-plan.md`](05-plan.md): **לוח זמנים.** השבוע הבא יום אחרי יום, ומשם ועד חנוכה ואחריו
3. [`01-snapshot.md`](01-snapshot.md): תמונת מצב. הכנסות, הוצאות, זמינות ונכסים
4. [`02-honest-review.md`](02-honest-review.md): איפה אתה יכול להשתפר, בלי ליפות
5. [`04-voice.md`](04-voice.md): השפה הכללית של המותג, ביו, טקסט "עליי", וטקסט חלופי לאתר של החווה
6. [`messages/yasmin.md`](messages/yasmin.md): ההודעה ליסמין
