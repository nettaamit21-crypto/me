# הנגרייה – דף נחיתה

דף נחיתה סטטי בעברית (RTL) לנגרייה פרטית שפועלת כמפעל מוגן ומרחב שיקומי.

## קבצים

- `index.html` – הדף המלא: עיצוב, תוכן וטופס יצירת קשר. קובץ יחיד ללא תלויות מלבד גופנים מ־Google Fonts.
- `content.md` – כל המלל השיווקי, מחולק לפי אזורים, לעריכה ולשימוש חוזר.

## מה צריך להחליף לפני עלייה לאוויר

1. **שם העסק** – כרגע "הנגרייה". חפשו והחליפו ב־`index.html` (לוגו, כותרת, פוטר).
2. **תמונות** – כל אלמנט עם המחלקה `ph` הוא ציין־מקום מעוצב עם כיתוב "תמונה: …". החליפו ב־`<img>` אמיתי או הגדירו `background-image` על האלמנט.
3. **כתובת אימייל** – המשתנה `CONTACT_EMAIL` בתחתית `index.html`. הטופס פותח הודעת מייל מוכנה; לחיבור לשירות טפסים (Netlify Forms, Formspree וכד') החליפו את ה־`submit` handler.
4. **קישור לקטלוג** – הכפתורים "לרכישה" מובילים כרגע לאזור המוצרים / יצירת קשר. כשתהיה חנות, עדכנו את ה־`href`.
