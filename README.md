# הנגרייה – דף נחיתה

דף נחיתה סטטי בעברית (RTL) לנגרייה פרטית שפועלת כמפעל מוגן ומרחב שיקומי.

## קבצים

- `index.html` – הדף המלא: עיצוב, תוכן וטופס יצירת קשר. קובץ יחיד ללא תלויות מלבד גופנים מ־Google Fonts.
- `content.md` – כל המלל השיווקי, מחולק לפי אזורים, לעריכה ולשימוש חוזר.

## מה צריך להחליף לפני עלייה לאוויר

1. **תמונות** – כל אלמנט עם המחלקה `ph` הוא ציין־מקום מעוצב עם כיתוב "תמונה: …". החליפו ב־`<img>` אמיתי או הגדירו `background-image` על האלמנט.
2. **קישורי רכישה** – כל כפתורי הרכישה מובילים לחנות המשק של חוות רום (`https://havatrom.co.il/חנות-המשק/`). כשמוצרי הנגרייה יעלו לחנות, אפשר לכוון כל כרטיס מוצר ישירות לעמוד המוצר שלו.
3. **טופס יצירת קשר** – פותח הודעת מייל מוכנה ל־nettaamit21@gmail.com (המשתנה `CONTACT_EMAIL` בתחתית `index.html`). לחיבור לשירות טפסים (Netlify Forms, Formspree וכד') החליפו את ה־`submit` handler.
4. **שם העסק** – כרגע "הנגרייה". אם יש שם מותג, חפשו והחליפו ב־`index.html` (לוגו, כותרת, פוטר).

# מחשבון הצעות מחיר – `quote.html`

כלי פנימי לנגרייה (לא מקושר מדף הנחיתה). קובץ יחיד שנפתח בכל דפדפן, גם בטלפון.

## מה יש בו

1. **תכנון ושרטוט** – שרטוט תלת־ממדי של המוצר עם סליידרים למידות, כמו באתרי רהיטים לפי מידה. משנים אורך או גובה, והשרטוט, רשימת החיתוכים והמחיר מתעדכנים מיד. אפשר לסובב את השרטוט ולסמן חלק בלחיצה.
2. **רשימת חלקים וחיתוכים** – כל חלק: כמות, עובי × רוחב × אורך (ס״מ), תמיד כמספרים. מספר עם סימן שרשרת משתנה לבד עם הסליידרים; הקלדת מספר אחר מקבעת אותו, וכפתור החץ המעגלי מחבר אותו בחזרה. הנוסחאות שמאחורי המספרים מוסתרות, ואפשר להציג אותן בתיבת סימון למתקדמים. אפשר גם להדביק רשימת חיתוכים כמו בדף העבודה (`2-A רגל ספסל 5X15X35`). בטלפון כל חלק מוצג ככרטיס.
3. **בנייה והזזת חלקים** – כפתור ליד השרטוט. בוחרים חלק, גוררים אותו בשרטוט (הוא נצמד לקצוות של חלקים אחרים), ומכוונים בכפתורים: הזזה ב-1/5/10 ס״מ, סיבוב, העמדה, הטיה במעלות (לרגליים משופעות כמו במתקן נדנדה), הנחה על מה שמתחת, עותקים ופריסה על כל האורך. כל פעולה אפשר לבטל.
4. **מחירון ועץ** – מזינים מחיר לקורה שלמה או מחיר למטר (השני מחושב). החלקים מותאמים לקורות לפי החתך, ומחושבות עלות העץ, כמות הקורות לקנייה ותכנית חיתוך עם שאריות. החישוב לפי מטר + פחת או לפי קורות שלמות.
5. **עלויות ורווח** – חומרים נוספים ושעות עבודה לכל מוצר, אחוז רווח מתוך המחיר (או על העלות), ואחוז מהמחיר שמשולם לחווה. שני האחוזים מופיעים גם ליד שם ההצעה, כי הם משתנים מפרויקט לפרויקט, והצעה חדשה מתחילה מהאחוזים של הקודמת. בנוסף: תוספות קבועות (הובלה), הנחה, עיגול ומע״מ, ופירוט לאן הולך כל שקל.
6. **הצעה ללקוח** – מסמך מוכן עם שרטוטים, מידות ומחירים: הדפסה ל-PDF, הורדה כקובץ, שמירה כתמונה או העתקת טקסט לוואטסאפ.
7. **דף עבודה** – רשימת חיתוכים לכל מוצר, קורות לקנייה ותכנית חיתוך, בלי מחירים.

**תמונות:** לכל מוצר אפשר לצרף כמה תמונות: כפתור "צירוף תמונות", גרירה של כמה קבצים יחד לכל מקום בדף, או הדבקה (Ctrl+V / Cmd+V). מתחת לשרטוט עוברים בין התמונות, מסירים, ובוחרים איזו מהן תופיע בהצעה ללקוח. JPG, PNG ו-WebP נתמכים; HEIC מאייפון עובד רק בדפדפנים שיודעים לפתוח אותו (Safari).

תבניות מוכנות: ספסל ושולחן זולה, ספסל עץ, אדנית, ונדנדת עץ עם מתקן ברגליים משופעות.

ההצעה לדוגמה בנויה לפי דף העבודה "פינת זולה לקטנטנים" (ספסל + שולחן). **המחירים בה לדוגמה בלבד.**

## שמירה

הכול נשמר אוטומטית בדפדפן. כשהכלי פתוח ב-Claude הוא גם מסתנכרן לחשבון, כך שהמחירון וההצעות זמינים בטלפון ובמחשב. "גיבוי" מוריד קובץ JSON שאפשר לשחזר ממנו.

## מוצר חדש מתמונה

- בתוך Claude: כפתור "שרטוט מתמונה" שולח את התמונה (ורשימת חיתוכים אם יש) ל-Claude, שמחזיר מודל עם סליידרים. "שינוי בעזרת Claude" מתקן מודל קיים לפי בקשה בעברית.
- מחוץ ל-Claude: שולחים את התמונה בצ׳אט, מקבלים JSON של מוצר, ומדביקים ב"+ מוצר" ← "ייבוא מוצר מקובץ או מטקסט".

### מבנה מוצר (JSON)

```json
{
  "name": "ספסל זולה לקטנטנים",
  "params": [
    { "key": "L", "label": "אורך", "type": "range", "min": 30, "max": 150, "step": 1, "value": 50 },
    { "key": "T", "label": "עובי רגל", "type": "const", "value": 5 },
    { "key": "D", "label": "עומק", "type": "calc", "expr": "3*10+T" }
  ],
  "parts": [
    { "code": "A", "name": "רגל ספסל", "n": "2", "t": "T", "w": "15", "l": "D",
      "orient": "Y-edge", "x": "0", "y": "0", "z": "0", "dx": "L-T", "dy": "0", "dz": "0" }
  ]
}
```

- צירים בס״מ: `x` אורך (משמאל לימין), `y` עומק (מקדימה לאחור), `z` גובה. `x,y,z` הם הפינה השמאלית־קדמית־תחתונה של החלק.
- `orient`: `X-flat`, `X-edge`, `Y-flat`, `Y-edge`, `Z-front`, `Z-side` – לאורך איזה ציר החלק שוכב ואיזה צד פונה למעלה.
- `n` עותקים במרווח `dx,dy,dz`; `n2` שורות נוספות במרווח `dx2,dy2,dz2`.
- סוגי פרמטרים: `range` (סליידר), `choice` (בחירה מתוך `options`), `const` (קבוע), `calc` (נוסחה).
