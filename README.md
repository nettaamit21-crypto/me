# הנגרייה – דף נחיתה

דף נחיתה סטטי בעברית (RTL) לנגרייה בחוות רום שפועלת כמפעל מוגן ומרחב שיקומי.

## קבצים

- `index.html` – הדף המלא: עיצוב, תוכן, שרטוטים וטופס יצירת קשר. קובץ יחיד ללא תלויות מלבד גופנים מ־Google Fonts.
- `content.md` – כל המלל השיווקי, מחולק לפי אזורים, לעריכה ולשימוש חוזר.

## כיוון עיצובי

במקום תמונות סטוק או ציינֵי מקום, הדף בנוי על **שרטוטי עבודה של נגר**: גיליון עם מבט חזית ומבט על, קווי מרכז, קווים נסתרים, חתך עם קווקוו ובלוק כותרת. השרטוטים מצוירים בקוד (SVG), מתאימים את עצמם למצב כהה, ולא מציגים מידות או חומרים שלא אושרו.

- רקע אבן `#F3F2EC`, נייר ליבנה `#EADFCB`, ירוק יער `#2B4533`, גרפיט `#3A3F3B`, כחול חוט־סימון `#3C6CB0` (לקווי מרכז בלבד).
- כותרות: Karantina (עברית צרה ובולטת). גוף: Assistant.
- הדף מגיב למצב כהה של המערכת.

## מה צריך להחליף לפני עלייה לאוויר

1. **תמונות אמיתיות** – הדבר שהכי יחזק את הדף. כשיהיו צילומים מהנגרייה (ידיים בעבודה, מוצרים, הסדנה, הנוף), אפשר להחליף את השרטוט בפתיח (`<figure class="sheet">`) ב־`<img>`, או להוסיף רצועת צילומים מעל המוצרים. כדאי להשאיר את שרטוטי המוצרים.
2. **קישורי רכישה** – כל כפתורי הרכישה מובילים לחנות המשק של חוות רום (`https://havatrom.co.il/חנות-המשק/`). כשמוצרי הנגרייה יעלו לחנות, אפשר לכוון כל מוצר לעמוד שלו.
3. **טופס יצירת קשר** – פותח הודעת מייל מוכנה ל־nettaamit21@gmail.com (המשתנה `CONTACT_EMAIL` בתחתית `index.html`). לחיבור לשירות טפסים (Netlify Forms, Formspree וכד') מחליפים את ה־`submit` handler.
4. **שם העסק** – כרגע "הנגרייה". אם יש שם מותג, מחפשים ומחליפים ב־`index.html` (לוגו, כותרת, פוטר, בלוק הכותרת בשרטוט).
